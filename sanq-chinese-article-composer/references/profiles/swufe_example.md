# Institution profile (example): SWUFE master's thesis

**This is an example of an optional institution profile, to be copied and adapted for another
university or journal.**
- It records the format norm of Southwestern University of Finance and Economics (西南财经大学)
  for master's theses (2007 version), as recorded by a student who applied it.
- **It is not an official document.** Check every value against the current official norm and
  the supervisor's instructions before using it.
- Load it only when the user says their thesis follows this norm.

## How to use a profile

- It overrides the general conventions of `07_format_by_document.md` (profile `thesis`) where
  they differ.
- If the user's supervisor gives a different instruction, the supervisor's latest instruction
  wins, and the difference is noted in the report.

## Values

| Item | Value |
|---|---|
| Body text | 宋体 小四, line spacing 1.37 |
| Level 1 heading | 二号 小标宋, centred, new page; numbering **「1.绪论」**, not 「第1章 绪论」, as in the norm's annex (annex 4) |
| Level 2 heading | 小三 黑体 (1.1) |
| Level 3 heading | 小四 黑体 (1.1.1) |
| Lower levels | （一）（二）（三） on their own line |
| Tables and figures | 五号; table titles in 黑体; notes in 小五 宋体; 注： under the table |
| Margins | 3.9 / 3.4 / 3.45 cm, as recorded; check which side each value applies to in the norm |
| Front matter | 扉页 (分类号, 密级, U.D.C., title in Chinese and English, 学号) → 原创性及知识产权声明 → 摘 要 → Abstract → 目录 |
| Page numbers | Roman before chapter 1, Arabic from 1 at chapter 1. The cover and the 目录 are not listed in the 目录 |
| Running heads | Thesis title and current chapter (recorded as: even pages the thesis title, odd pages the chapter); check against the norm |
| Keywords | 关键词： in bold, without indentation, keywords separated by ； |
| Glossary | If any, at the end as 附录 术语表 |
| References | GB/T 7714, numbered [1]…[n], Chinese sources first |
| Table note convention used by supervisors in this programme | 注：***、**、*分别表示在1%、5%、10%的水平上显著，括号中为聚类稳健标准误。 |
